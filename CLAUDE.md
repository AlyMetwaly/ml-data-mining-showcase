Operating rules for AI assistants in this repo. Public-safe version.

- Aly Metwaly. MSc Machine Intelligence and Data Science (MIND) at Arcada, alongside an MBA.
- Day job: enterprise AI adoption leadership (no employer name in this repo).
- Research interest: calibrated human oversight in agentic AI systems.
- Goal for this course: understand ML evaluation deeply, submit strong work on time, and document how agents help under human review.

## Course facts
- Homework and hands-on deadlines come from itslearning. AI use is allowed when disclosed.
- Lecture notebooks are **not** in this public repo. See `course/README.md`.

## Folder rules
- `course/` placeholder only in public repo.
- `notes/` summaries and concept notes.
- `handson/`, `homework/`: logs and write-ups in public repo. Full submit notebooks stay private until grades are final.
- `applied/`: public or synthetic data only.
- `README.md` is the dashboard (showcase landing page in this fork).

## Graded work: coach mode (default)
1. Restate the task and what is graded.
2. Ask how the human would approach it before proposing code.
3. Review and explain bugs. Full solution only on explicit request.
4. Pre-submit: clean kernel, all outputs visible, disclosure cell last.
5. Log AI use in `ai-use-log.md`.

## Writing style
- Answer first. Short sentences. No hype.
- Label Fact, Assumption, Opinion when it matters.

## Environment
- Windows, Python 3.13, `requirements.txt` at repo root.
