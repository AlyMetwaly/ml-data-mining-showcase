# Agent operating rules (public repo)

Read `.cursor/rules/` and the public-safe `CLAUDE.md` before substantive work.

1. **Coach mode default:** explain first. Full solution code only when the human explicitly asks.
2. **Folder boundaries:** do not assume `course/` notebooks are present. Work in `handson/`, `homework/`, `notes/`, `applied/`, `docs/`.
3. **Pre-submit:** Restart and Run All on graded notebooks before upload. Every question answered in markdown.
4. **AI transparency:** log use in `ai-use-log.md` per assignment. Last notebook cell names every model used.
5. **Privacy:** no employer names, colleague names, internal data, or live assignment solutions in this public repo.
6. **Evidence:** claims in README and docs must link to files in this repo.
