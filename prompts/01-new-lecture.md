# New lecture prompt (after each lecture)

Read CLAUDE.md. Lecture N materials are in `course/LectureN/` (and transcript in `course/transcripts/` if I added one).
1. Identify the primary notebook. Ignore instructor/student duplicates unless the lecturer said otherwise.
2. Find the hands-on task. Report it in plain words and add its deadline to README.
3. Make a working copy in `scratch/LN/`. Run it. Report errors and fix the environment if needed.
4. Write the lecture summary and new concept notes using the templates. Link to existing concepts instead of repeating them.
5. Add the new concepts to `notes/cheatsheet.md`.
6. Add 1 to 3 applied ideas to `applied/ideas.md`, only if real.
7. Update README and commit.
